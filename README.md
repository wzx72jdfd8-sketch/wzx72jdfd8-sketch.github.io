# Earth globe

3D Earth with the full GPS operational constellation and the CelesTrak GEO catalogue, propagated with SGP4.

**Live site:** https://wzx72jdfd8-sketch.github.io/

- Orbital data: [CelesTrak](https://celestrak.org/)
- Earth textures: three.js examples (NASA-derived)
- Propagation: [satellite.js](https://github.com/shashwatak/satellite-js)
